### Retired Artifacts

This page lists the artifacts in this implementation guide whose `status` is `retired`. They are
still published and still resolve, so any existing binding against them keeps working — but they
should not be used for new work. Each description states what replaced it.

The tables below are generated at build time by filtering the published artifact list on
`status`, so they stay in sync automatically as resources are retired. Nothing here needs to be
maintained by hand.
